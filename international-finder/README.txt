REGAINTRAVEL AI — INTERNATIONAL FINDER (UK STARTER)

This is a self-contained, local Windows application. It is a standalone module, not a patch to your previous project (which was not attached).

INSTALL:
1. Extract the ZIP to a folder, e.g. Documents\RegainTravel_International_Finder.
2. Install Python 3 from python.org if needed. Tick 'Add Python to PATH'.
3. Double-click START_WINDOWS.bat.
4. Browser opens at http://127.0.0.1:8765 (if not, paste this address manually).
5. Leave the black terminal window open while using the application. Close it to stop.
6. Use Discover > open a public search > manually review results > Save lead.
7. Use Recruitment / Holiday customers to update lead statuses. Export CSV to back up.

IMPORTANT:
- This version generates live public search links; it does NOT automatically collect or verify leads, scrape platforms, send messages, or use an LLM API.
- Reddit API access needs explicit approval. LinkedIn/Facebook access must respect their terms. Do not bypass access controls.
- Country flags are a small starting reference, not an exhaustive live legal database. Check latest official PlanNet and InteleTravel rules before recruiting or selling.
- UK GDPR/PECR and platform rules may apply to marketing outreach. Do not collect unnecessary personal data or contact people without a lawful basis.
- Database is local: regaintravel.db (created on first run). Back up this file regularly.
- App only listens on your computer (127.0.0.1); not publicly exposed.
- Python standard library only; no pip install required.
